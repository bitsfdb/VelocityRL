Features

Everything you need to swap

⇄

Two-step swapper

Select the item you own, pick a target look, and apply. The UI keeps item types matched automatically.

↩

Automatic backups

Every swap creates a backup of your original files. Restore individual items or revert everything in one click.

⚡

Native engine

Swaps run through a built-in Rust UPK engine — no external tools, no Python runtime required.

🔍

Full item database

Search thousands of Rocket League items by name, filtered by category — bodies, decals, wheels, boosts, and more.

🛡

Safe & reversible

Modifications are local to your game files. Restore anytime from the built-in backup manager.

🖥

Cross-platform desktop

Built with Tauri for a lightweight native app on Windows, macOS, and Linux.
